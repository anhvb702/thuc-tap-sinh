# PH3-02: Pantry compartments

## Contract
- `PantryItem.compartment` defaults to `CHILL`; existing `PantryEntity` rows remain readable because compartment is stored separately.
- `PantryRepositoryImpl.observe` combines pantry rows and compartment rows; missing companion rows map to `CHILL`. `setCompartment` persists the selected value.
- `daysLeft` uses `(userShelfDays ?: defaultShelfDays) * 10` for `FREEZE` and the selected shelf days for `CHILL`.
- `expiringList` omits `FREEZE` items regardless of their estimated days remaining.
- Home priorities and the pantry "Nên dùng sớm" tab follow the same exclusion; Home's compartment counts use saved values rather than ingredient-type guesses.
- Pantry cards expose a reachable control that toggles CHILL/FREEZE and saves through the repository; storage tabs follow the item's selected compartment.

## Tests and mutations
- Repository round trip/default test: changing compartment persists and a legacy pantry row without a companion row is CHILL. Catch reversed mapping, ignored writes, and missing default.
- Shelf tests: custom and default shelf-day values are multiplied by ten only when frozen. Catch factor 1, wrong base value, and applying factor to CHILL.
- Expiring-list test: frozen urgent item is absent while a chilled urgent item remains. Catch missing or inverted exclusion.
- Reducer test: toggle switches compartment and emits matching `SaveCompartment`; catch unchanged state or missing persistence effect.
- Presentation test: selected storage tab filters by persisted compartment and UI provides toggle action. Catch fixed ingredient classification or missing control.

## Six mutation cases
1. Force every item to `CHILL`: frozen shelf-life test must fail.
2. Multiply shelf days by 1 instead of 10: frozen shelf-life test must fail.
3. Multiply `defaultShelfDays` while ignoring `userShelfDays`: custom override test must fail.
4. Remove the `FREEZE` exclusion: expiring-list test must fail.
5. Reverse CHILL/FREEZE serialization or reducer mapping: repository/reducer round-trip test must fail.
6. Remove the save effect or use ingredient classification for tab filtering: reducer/presentation test must fail.

## Biên và rủi ro
- Existing databases have no compartment row; they must behave as CHILL until changed.
- Toggling an item not in the catalog is ignored. Unchecked pantry items may retain their compartment for the next add.
- Shelf dates remain estimates; frozen items are excluded only from the daily expiring priority list.
