# P12-03R — Giữ công thức đang mở khi thứ tự gợi ý thay đổi

## Hợp đồng

**Mục tiêu:** Sau khi người dùng mở công thức từ Home hoặc chọn công thức khác ở tab Món ăn, thay đổi thứ tự recommendation do state pantry không được âm thầm đổi lựa chọn nếu ID đó vẫn có.

**Input:** ID đang chọn, ID yêu cầu mới từ Home (có thể null/invalid), danh sách recommendation mới có cùng/đổi thứ tự/loại ID đã chọn.

**Expected Output:**

- ID yêu cầu mới hợp lệ được chọn.
- Nếu không có yêu cầu mới, giữ ID đang chọn khi nó vẫn nằm trong recommendations, kể cả thứ tự thay đổi.
- Nếu ID đang chọn không còn, fallback về ID đầu tiên hiện có; list rỗng trả null.
- Home request không hợp lệ khi mở mới fallback an toàn về đầu tiên; link chung không tái sử dụng ID cũ.
- Request cuộn từ Home chỉ được dùng một lần; sau khi người dùng chọn recipe khác, filter/reset/reorder không tự cuộn ngược về request cũ.

## Sáu mutation

1. Luôn chọn recommendation đầu tiên khi thứ tự thay đổi.
2. Không nhận ID yêu cầu hợp lệ từ Home.
3. Giữ ID cũ dù nó đã biến mất khỏi danh sách.
4. Giữ ID Home cũ khi link chung không có target.
5. ID request không hợp lệ gây crash hoặc null dù có recommendation.
6. Danh sách rỗng vẫn tạo ID không tồn tại.
7. Không tiêu thụ request cuộn sau lần đầu và kéo người dùng về thẻ cũ khi filter được reset.

## Bằng chứng

Chờ test-first RED, state selection tests, mutations, Compose suite và kiểm thao tác sau khi nấu trên emulator.
