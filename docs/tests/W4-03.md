# W4-03 — Đơn vị số lượng và trợ năng tủ lạnh

## Hợp đồng nghiệm thu

### Mục tiêu

Cho phép chọn đơn vị cho từng món bằng danh sách ngắn, lưu offline qua SQLDelight, hiện cạnh số lượng. Mặc định là `phần`; lựa chọn về mặc định xóa override. Danh sách cố định: `phần`, `cái`, `quả`, `bó`, `g`, `kg`, `hộp`, `chai`. Không bắt nhập đơn vị tự do.

### MVI/repository

| Test | Input | Expected Output | Mutation bắt |
| --- | --- | --- | --- |
| `Loaded` | pantry, quantity và unit override | state giữ đúng unit theo ingredient | bỏ load map |
| `OpenUnitEditor` | món không có override / có override | dialog chọn `phần` / giá trị override hiện tại | chọn default sai |
| `PickUnit` | unit hợp lệ / lạ | hợp lệ cập nhật lựa chọn; lạ bị bỏ qua | bỏ whitelist |
| `SaveUnitEditor` | chọn `quả` | state cập nhật, phát `SaveUnit(id,"quả")` | bỏ effect |
| `SaveDefaultUnit` | chọn `phần` | override bị xóa (`null`) và UI vẫn hiển thị phần | lưu dòng mặc định |
| `CancelUnitEditor` | editor mở | editor đóng, không effect | ghi khi cancel |
| Repository persist/default | `setUnit(quả)`, rồi `setUnit(null)` | Flow phát map và cuối cùng rỗng | bỏ ghi/xóa |
| Repository rejects invalid | unit ngoài danh sách | lỗi, DB không đổi | bỏ validation |
| Migration v2→v3 | các bảng hiện tại có dữ liệu | giữ nguyên, unit table mới rỗng | migration mất dữ liệu |

### UI và trợ năng

- Thẻ hiện ví dụ `2 phần`; nhãn này là số lượng tĩnh. Nút riêng `Đổi đơn vị · phần` mở danh sách chọn nhanh, vùng chạm tối thiểu 48dp.
- Bộ lọc dùng `FlowRow`; nhãn đếm kết quả tách riêng, các nút tối thiểu 48dp.
- Các nút +/− và lựa chọn đơn vị có mô tả TalkBack; text chính/phụ tương phản tối thiểu WCAG AA, màn hình rộng 360dp không cắt nội dung; font lớn có thể cuộn.
- Không đổi màu trạng thái ước tính thành lời khẳng định an toàn thực phẩm.

### Sai lệch hợp đồng/source cần xử lý

- Câu “lưới thẻ cao 180dp ... 320dp” là tiêu chí chiều cao; source hiện dùng `GridCells.Adaptive(minSize = minColumnWidth)` với 180dp/320dp làm **chiều rộng tối thiểu cột**, không đặt chiều cao thẻ. Giữ nguyên contract lịch sử này, không coi bố cục đạt cho tới khi có quyết định/chỉnh contract riêng và runtime đo xác nhận.
- Nội dung trước đây nói “bấm nhãn đơn vị” không khớp UI hiện tại: số lượng có nhãn tĩnh, nút “Đổi đơn vị · …” mới mở dialog.

### Sao lưu

Unit override là dữ liệu người dùng offline nên phải nằm trong export/restore JSON. Giữ nguyên khả năng đọc backup cũ không có trường `units`; backup mới ghi trường này.

## Biên bản

### Mutation probes

| Mutation | Kết quả | Bằng chứng |
| --- | --- | --- |
| Bỏ load unit overrides | Bị bắt | `cells_showSavedUnitOrDefaultPhan` và editor test đỏ. |
| Bỏ whitelist trong reducer | Bị bắt | `pickUnit_acceptsAllowedValueAndRejectsUnknownValue` đỏ. |
| Lưu `phần` thành override thay vì `null` | Bị bắt | `saveDefaultUnit_removesOverrideAndPersistsNull` đỏ. |
| Bỏ ghi repository | Bị bắt | persist, validation và pantry-independence tests đỏ. |
| Bỏ validate unit trong codec | Bị bắt | `decode_rejectsUnsupportedUnitOverride` đỏ. |
| Bỏ xóa unit table khi restore | Bị bắt | replacement và empty-restore tests đỏ. |

Mutation đầu tiên ban đầu làm Kotlin compile lỗi nên không tính; đã thay bằng mutation hợp lệ `unitOverrides = emptyMap()`, và test hành vi đó đỏ. Mọi probe được khôi phục trước suite cuối.
