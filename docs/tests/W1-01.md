# W1-01 — Spec test hạn dùng (Shelf)

File test: `shared/src/commonTest/kotlin/com/loitu/yourrefri/feature/pantry/logic/ShelfTest.kt`

Hợp đồng: `daysLeft = (markedAt + (userShelfDays ?: defaultShelfDays) ngày) - today` (số ngày lịch); `urgencyOf`: `<0` EXPIRED, `0..2` SOON, `>=3` OK. Hàm thuần, ngày cố định trong test, không dùng `Clock.System`.

## Mutation dùng để rà

| Mã | Mutation (code sai) |
|----|---------------------|
| M1 | Trừ ngược dấu: `today - expiry` |
| M2 | Bỏ qua `userShelfDays`, luôn dùng `defaultShelfDays` |
| M3 | Luôn dùng `userShelfDays` (null → 0), không rơi về default |
| M4 | Coi `userShelfDays = 0` là "không có" (`takeIf { it > 0 }`) |
| M5 | Lệch 1 ngày: tính hạn bao gồm ngày cuối (`+1`) hoặc `-1` |
| M6 | Biên EXPIRED sai: `<= 0` thay `< 0` |
| M7 | Biên SOON/OK sai: `<= 3` là SOON, hoặc `< 2` là SOON (2 thành OK) |
| M8 | Tính ngày bằng `dayOfMonth`/`dayOfYear` hiệu đơn giản (sai qua tháng/năm) |
| M9 | Bỏ qua năm nhuận (tháng 2 luôn 28 ngày, năm luôn 365 ngày) |
| M10 | Kết quả phụ thuộc `have` (ví dụ `have=false` trả 0 hoặc hết hạn) |
| M11 | `urgencyOf` làm phép tính trước khi so sánh nên tràn số với giá trị cực (ví dụ `x + 1 > 3`, `x - 1 < -1`) |
| M12 | Lấy `abs()` của chênh lệch ngày (mất dấu khi đã hết hạn) |

## Khoảng trống đã biết

- Không kiểm `userShelfDays`/`defaultShelfDays` âm: hợp đồng không định nghĩa, cần quyết định trước khi thêm test.
- Không kiểm `daysLeft` với khoảng ngày cực lớn (tràn `Int`): ngoài phạm vi thực tế.
- Không kiểm múi giờ: hợp đồng chỉ dùng `LocalDate`, việc đổi `Instant` → `LocalDate` theo `TimeZone` thuộc tầng gọi.
