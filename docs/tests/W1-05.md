## API đã chốt

`shared/src/commonMain/kotlin/com/loitu/yourrefri/feature/pantry/data/PantryRepository.kt`:

```kotlin
interface PantryRepository {
    /** Mọi dòng tủ (kể cả have=false), sắp theo ingredientId; phát lại mỗi khi bảng đổi. */
    fun observe(): Flow<List<PantryItem>>
    /** ingredientId -> hạn sửa tay (ngày); không có ghi đè thì không có khóa. Phát lại khi đổi. */
    fun observeShelfOverrides(): Flow<Map<String, Int>>
    /** markedAt = null: lấy ngày từ Clock + TimeZone tiêm (have=true) hoặc giữ ngày cũ (have=false). Có giá trị: ghi đúng ngày đó. */
    suspend fun setHave(ingredientId: String, have: Boolean, markedAt: LocalDate? = null)
    /** null = bỏ ghi đè; 0 là giá trị hợp lệ; âm ném IllegalArgumentException. */
    suspend fun setShelfDays(ingredientId: String, days: Int?)
}
```

`shared/src/commonMain/kotlin/com/loitu/yourrefri/feature/pantry/data/PantryRepositoryImpl.kt`:

```kotlin
class PantryRepositoryImpl(
    db: YourRefriDatabase,
    clock: kotlin.time.Clock,
    timeZone: kotlinx.datetime.TimeZone,
    ioContext: kotlin.coroutines.CoroutineContext,
) : PantryRepository
```

- `Clock` là `kotlin.time.Clock` (kotlinx-datetime 0.7.x đã bỏ `kotlinx.datetime.Clock`); cần `@OptIn(ExperimentalTime::class)`.
- `ioContext` được tiêm cho `asFlow().mapToList(ioContext)`; app truyền `Dispatchers.IO`, test truyền `StandardTestDispatcher(testScheduler)`.
- Không gọi `Clock.System` hay `TimeZone.currentSystemDefault()` trong `shared/src/commonMain` (Sonnet grep khi kiểm).
- Lệch so với PLAN: PLAN ghi `setHave(id, have, now)`; bản chốt lấy "now" từ `Clock` tiêm vào constructor. Tham số `markedAt` tùy chọn chỉ để khôi phục ngày cũ (effect `SaveHave(id, have, markedAt)` của reducer W1-06 khi chạm nhầm 2 lần), không phải để truyền "now".

Hành vi:
- `setHave(id, true, markedAt)`: upsert `have=true`, ngày = `markedAt ?: clock.now().toLocalDateTime(timeZone).date`, ghi chuỗi ISO. Gọi lại khi đã có thì cập nhật ngày mới. `markedAt` trong quá khứ được ghi nguyên.
- `setHave(id, false, null)`: `updateHave(false, id)`; giữ dòng và `markedAt` cũ.
- `setHave(id, false, markedAt)` trên món đã có: `have=false` và ghi đè `markedAt` bằng giá trị truyền vào.
- `setHave(id, false, *)` với id chưa có: không làm gì, kể cả khi có `markedAt`.
- `setShelfDays(id, n)`: `n == null` xóa ghi đè; `n >= 0` upsert; `n < 0` ném `IllegalArgumentException` trước khi ghi. Không động vào bảng pantry.
- `observe()` đổi `PantryEntity` → `PantryItem` (`LocalDate.parse`). `observeShelfOverrides()` đổi `Long` → `Int`.

Phần ghép `Ingredient.userShelfDays` từ `observeShelfOverrides()` thuộc tầng gọi (reducer W1-06 / ShelfTable W1-03), không thuộc repository.

## Cách test

- `FakeClock(var current: Instant) : Clock`, mốc 2026-03 (khác ngày thật để code lén dùng giờ hệ thống bị lộ). Tiến thời gian bằng `clock.current += n.days`.
- Múi giờ: `TimeZone.UTC`, `UtcOffset(hours = 7).asTimeZone()`, `UtcOffset(hours = -5).asTimeZone()` (offset cố định, không phụ thuộc tzdb hay múi giờ máy).
- `runTest` + `StandardTestDispatcher(testScheduler)`; kiểm phát lại bằng `backgroundScope.launch { collect }` + `runCurrent()`.

## Khoảng trống đã biết

- Không kiểm hủy/đóng flow, lỗi I/O, hay ghi đồng thời từ nhiều coroutine.
- `setHave(true)` nhiều lần trong cùng ngày vẫn ghi lại (không kiểm có phát thừa hay không).
- Không có thao tác xóa hẳn một món khỏi tủ; nếu cần sẽ là task riêng.
- Không kiểm `ingredientId` lạ (không có trong bảng hạn W1-03): repository không biết bảng hạn, việc lọc thuộc tầng gọi.
