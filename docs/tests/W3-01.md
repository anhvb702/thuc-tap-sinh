# W3-01 — RecipeBundle.parse

`feature/recipe/data/RecipeBundle.kt`: `object RecipeBundle { fun parse(json: String): List<Recipe> }`.

JSON gốc là mảng object, mỗi recipe có id/title chuỗi, steps mảng chuỗi, required mảng slot; optional mảng slot mặc định []. Slot object chỉ có anyOf mảng chuỗi bắt buộc. Reject mọi trường lạ ở mọi tầng, gồm quantity/amount/unit. Không định lượng dạng trường dữ liệu; parser không phân tích số trong câu hướng dẫn. Reject syntax lenient, missing/null, kiểu sai. Chuyển qua model Recipe/Slot để dùng validation đã chốt (id/title/step/anyOf không blank, steps1..8, required không rỗng, slot không rỗng). ID recipe duy nhất, lỗi chứa id trùng. Giữ thứ tự recipes/steps/slot/anyOf, kể cả anyOf trùng. Không sửa model annotation; dùng DTO nội bộ. Không thêm ràng buộc id kebab-case hay kiểm nguyên liệu thuộc bảng ở task này vì chưa có hợp đồng tương ứng.

| Test | Input | Kết quả | Mutation bắt |
|---|---|---|---|
| validBundle_preservesAllFieldsAndOrder | 2 recipe đảo id, steps2, required alternatives, optional | đúng model nguyên thứ tự | sort; bỏ optional; đổi bước |
| optionalOmitted_defaultsEmpty | không optional | [] | bỏ default |
| emptyArray_returnsEmpty | [] | [] | reject rỗng |

Không bundle công thức thật, không thêm thư viện: dùng kotlinx-serialization-json đã có. Không xác nhận an toàn hay giá trị dinh dưỡng từ nội dung JSON.
