# A-08 — Lịch sử nấu: logic nhóm theo tuần

## Mục tiêu

Hàm thuần gom `CookLog` thành các nhóm "Tuần này / Tuần trước / Trước đó" cho màn "Đã nấu".

## Input và Expected Output

- `groupCookHistory(logs: List<CookLog>, today: LocalDate): List<CookHistoryWeek>`; `CookHistoryWeek(label, entries)`; `CookHistoryWeekLabel { THIS_WEEK, LAST_WEEK, EARLIER }`.
- Tuần bắt đầu Thứ Hai. `date >= thứ Hai tuần này` → `THIS_WEEK` (kể cả ngày tương lai); `date >= thứ Hai tuần trước` → `LAST_WEEK`; còn lại `EARLIER`.
- Giữ thứ tự đầu vào trong mỗi nhóm; nhóm theo thứ tự cố định; bỏ nhóm rỗng; đầu vào rỗng → rỗng.
- Không thống kê, không so sánh, không điểm số.
