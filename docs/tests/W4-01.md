# W4-01 — weeklyReview

Hàm thuần `feature/pantry/logic/WeeklyReview.kt`:

```kotlin
fun weeklyReview(pantry: List<PantryItem>, changes: Map<String, Boolean> = emptyMap()): List<PantryItem>
```

`changes` biểu diễn giá trị have cuối cùng người dùng chọn; không phải danh sách toggle. Mặc định “đúng hết” trả dữ liệu nguyên giá trị. Chỉ các ID có trong pantry và changes được đổi have; giữ nguyên ingredientId, markedAt và vị trí. Không làm mới ngày chỉ vì xác nhận tuần, kể cả bật false→true. Không tạo dòng từ id lạ. Không sửa input. ID pantry duy nhất theo DB. Caller lưu kết quả cần truyền markedAt rõ ràng để repository không tự đổi ngày. Không có effect lưu trong hàm.

| Test | Input | Kết quả | Mutation bắt |
|---|---|---|---|
| defaultReview_keepsEveryField | true/false, ngày cũ khác nhau | nguyên danh sách | mặc định false/true; làm mới ngày |
| explicitEmptyReview_keepsEveryField | map[] | nguyên | reset các dòng |
| onlyTouchedItemChanges | egg,rice; egg→false | chỉ egg false, ngày giữ | đổi tất cả; bỏ false |
| selectedOutItemBecomesHave_withoutRefreshingMarkedAt | egg false cũ→true | true ngày cũ | luôn false; ngày mới |
| selectedValueIsFinal_notAToggle | true→true,false→false | nguyên | toggle thay assignment |
| unknownIds_areIgnored | id lạ→true/false | không dòng mới, input nguyên | tạo dòng lạ |
| multipleChanges_preservePantryOrder | pantry z,a,b; changes b,z | z,a,b cùng ngày cũ | sort/đảo theo map |
| emptyPantry_returnsEmpty | [] và changes có id | [] | tạo item từ changes |
| inputsRemainUnchanged_acrossRepeatedCalls | mutable list/map, gọi hai lần | kết quả bằng nhau, input nguyên | mutate input; toggle |

Một lựa chọn cuối cho mỗi mục sửa cho phép UI dùng k lần chạm và một xác nhận; “đúng hết” không cần chạm từng dòng. Chưa có test UI hoặc bằng chứng thời gian ≤30s: phải đo ở W5-01, hàm thuần không chứng minh thời gian thao tác.

Giới hạn: khi bật lại món đã đánh dấu không có, việc giữ ngày cũ hay hỏi ngày mua là quyết định sản phẩm cần chốt trước tích hợp. Hàm này chỉ tính trạng thái theo ngày dữ liệu hiện có, chưa kết nối UI/repository thành hành vi cuối.
