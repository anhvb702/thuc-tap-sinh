# W1-07a — nối reducer với repository

`PantryGridViewModel(repository, ingredients, clock, timeZone, scope)` kế thừa ViewModel; `scope` mặc định viewModelScope, test tiêm backgroundScope. Xuất `state: StateFlow<PantryGridState>` và `dispatch(action)`.

Có `refresh()` để nạp snapshot hiện tại khi màn hình trở lại foreground. Observation chỉ phát tín hiệu refresh; actor đọc lại snapshot mới nhất từ repository khi xử lý tín hiệu, không áp payload cũ đã xếp hàng. Self-write refresh giữ `sessionBase` để hai lần chạm khôi phục đúng ngày cũ; resume refresh xóa `sessionBase` trước khi nhận snapshot mới nhưng vẫn giữ editor đang mở. Trước mỗi Tap, ngày state được tính lại từ Clock/TimeZone đã tiêm.
