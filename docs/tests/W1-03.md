> Hạn trong bảng là hạn **ƯỚC TÍNH** để nhắc "nên dùng trước", không phải lời khuyên an toàn thực phẩm. UI luôn ghi nhãn "ước tính" và cho sửa.

## Hợp đồng (Haiku cài đúng chữ ký này)

File `shared/src/commonMain/kotlin/com/loitu/yourrefri/feature/pantry/data/ShelfTable.kt`:

```kotlin
package com.loitu.yourrefri.feature.pantry.data

object ShelfTable {
    val GROUPS: Set<String> = setOf("thit", "ca", "rau-la", "rau-cu", "trai-cay", "sua-trung", "khac")
    // Ném IllegalArgumentException khi JSON hỏng hoặc dữ liệu vi phạm quy tắc dưới đây.
    fun parse(json: String): List<Ingredient>
}
```

Định dạng JSON (gốc là **mảng**, mỗi phần tử đúng 4 trường, không trường nào tùy chọn):

```json
[
  { "id": "rau-muong", "nameVi": "Rau muống", "group": "rau-la", "defaultShelfDays": 2 }
]
```

Quy tắc của `parse`:
1. Trả về `Ingredient` theo **đúng thứ tự trong file**, `userShelfDays = null`. `"[]"` → `emptyList()`.
2. JSON hỏng, gốc không phải mảng, chuỗi rỗng, thiếu trường, `defaultShelfDays: null` → `IllegalArgumentException`. (`kotlinx.serialization.SerializationException` đã là lớp con của `IllegalArgumentException`, cho lọt ra là đạt; không bọc thành kiểu khác không phải IAE.)
3. `id` blank → lỗi. `id` trùng → lỗi, **message chứa id trùng**.
4. `nameVi` blank (`""`, `"   "`) → lỗi, **message chứa id**.
5. `defaultShelfDays` ngoài `1..365` → lỗi, **message chứa id**.
6. `group` không thuộc `GROUPS` (so khớp chính xác, phân biệt hoa thường) → lỗi, **message chứa giá trị group sai**.
7. Dùng `Json` mặc định (không `isLenient`, không `coerceInputValues`). DTO `@Serializable` nội bộ (`internal`/`private`), không gắn `@Serializable` vào `Ingredient`.
