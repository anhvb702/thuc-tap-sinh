# W5-01 — Persona UX follow-up

## Contract before implementation

| Task | Input | Expected output | Mutation to catch |
| --- | --- | --- | --- |
| Unknown food name | typed text not present in catalog | no catalog ingredient is selected; dialog can show a retry message | fallback to first missing ingredient |
| Known food name | trimmed, case-insensitive catalog name | matching catalog ingredient is selected | case-sensitive or whitespace-sensitive lookup |
| Similar names | exact catalog match and ambiguous prefix | exact name wins; ambiguous partial name is not selected | `firstOrNull` chooses shorter first item |
| Add ingredient with estimated days | catalog item not already present, days in `SHELF_DAY_OPTIONS` | emits `SaveHave(id,true,today)` and `SaveShelfDays(id,days)`; state shows it present with selected estimate | ignore selected days or toggle unrelated item |
| Re-add after marking out | previously present item has old date, then explicit Add | new marked date is injected current local date | restore the old session base date |
| Already present | matched item has `have=true` | no mutation/effect | toggle an existing item off |
| Expiring item copy | negative estimated days | Home uses the shared estimate copy and never displays a negative day count | raw `daysLeft` interpolation |
| Empty urgent list | no item due soon | neutral copy without prohibited expiry or scoring language | restore “hết hạn” or evaluative praise |

## Implementation note

Catalog-only data means free text cannot create a new food row. A failed lookup must keep the selection unchanged and invite the user to retry; it must never toggle an unrelated food.

## Persona review and verification

Persona Chị Mai/Anh Nam rà source hai lượt; không dùng persona để kết luận trải nghiệm runtime. Các finding được xử lý:

- Trang chủ dùng `statusText` cho ước tính âm và không còn câu khen/chấm điểm.
- Gợi ý không còn tự nhận tận dụng món cần dùng sớm hoặc đủ nguyên liệu nếu chưa đối chiếu state.
- Nhãn công thức không xếp hạng món.
- Tên nhập không khớp không toggle món đầu tiên; món đã có không bị chuyển thành “hết”.
- Khi thêm món từ catalog, `AddIngredient(id, days)` lưu cả trạng thái có và số ngày ước tính đã chọn. Test bảo vệ unknown name, case/space, ngày ước tính, và món đã có.
- Persona cuối yêu cầu lời nhắc có cụm “lúc 17:30” và nhãn đếm “Tất cả món (n)”; copy đã được chỉnh. Reviewer source cuối không còn finding chặn.
