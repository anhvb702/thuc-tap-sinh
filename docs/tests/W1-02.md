package com.loitu.yourrefri.feature.recipe.data

data class Slot(val anyOf: List<String>) {
    init {
        require(anyOf.isNotEmpty()) { "..." }
        require(anyOf.all { it.isNotBlank() }) { "..." }
    }
}

data class Recipe(
    val id: String,
    val title: String,
    val steps: List<String>,
    val required: List<Slot>,
    val optional: List<Slot> = emptyList(),
) {
    init {
        require(id.isNotBlank())
        require(title.isNotBlank())
        require(steps.isNotEmpty() && steps.size <= 8)
        require(steps.all { it.isNotBlank() })
        require(required.isNotEmpty())
    }
}

File `shared/src/commonMain/kotlin/com/loitu/yourrefri/feature/cooklog/data/Models.kt`:

```kotlin
package com.loitu.yourrefri.feature.cooklog.data

data class CookLog(
    val id: Long,
    val recipeId: String,
    val cookedOn: kotlinx.datetime.LocalDate,
    val photoUri: String? = null,
    val savedIngredientIds: List<String>,
)
```

Quy tắc:
- Mọi vi phạm ném `IllegalArgumentException` (dùng `require`, không dùng `check`/`error`).
- Kiểm tra nằm trong `init` (để `copy()` cũng bị chặn), không đặt trong hàm factory.
- "Rỗng" nghĩa là blank: `""` và `"   "` đều lỗi.
- `CookLog` không có ràng buộc (id do DB cấp; danh sách đồ đã dùng có thể rỗng).
- Không thêm kotlinx-serialization vào các model này (W3-01 tự có DTO riêng).

Quyết định Opus thêm ngoài yêu cầu gốc (người dùng có thể bỏ, khi đó xóa test tương ứng qua thẻ có ghi rõ): phần tử `anyOf` không blank, từng bước không blank, `required` không rỗng (món không cần nguyên liệu nào sẽ luôn "nấu được" và làm hỏng `suggest`).

- Không kiểm id trùng trong `anyOf` (`["a","a"]`): chưa quyết định là lỗi hay cho phép.
- Không kiểm `required` và `optional` trùng nguyên liệu: để W3-01 (validator bundle) quyết định.
- Không kiểm định dạng id (kebab-case): để W3-01/W1-03.
- `CookLog.recipeId` blank không bị chặn: DB và W3-05 chịu trách nhiệm.
