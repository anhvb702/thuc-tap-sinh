# W2-01 — expiringList

Hàm thuần tại `feature/pantry/logic/ExpiringList.kt`:

```kotlin
data class ExpiringItem(
    val item: PantryItem,
    val ingredient: Ingredient,
    val daysLeft: Int,
    val urgency: Urgency,
)
fun expiringList(pantry: List<PantryItem>, ingredients: List<Ingredient>, today: LocalDate): List<ExpiringItem>
```

Chỉ lấy món `have=true`, có metadata trong ingredients, urgency là EXPIRED hoặc SOON (daysLeft <=2 theo W1-01). Không đưa OK vào danh sách nhắc. Id không có metadata bị bỏ vì không xác định được hạn. Input từ repository/table có id duy nhất. Sắp `daysLeft` tăng rồi `ingredientId` tăng, nên EXPIRED đứng đầu và không phụ thuộc thứ tự input. Dùng hạn ghi đè, kể cả 0; ngày do caller truyền; không đổi input, không đọc đồng hồ.
