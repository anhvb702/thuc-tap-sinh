## Quyết định đã chốt

- Database tên `YourRefriDatabase`, package `com.loitu.yourrefri.shared.db`.
- Ba file `.sq`, mỗi file một bảng, tên bảng có hậu tố `Entity` để không trùng với model miền `feature.pantry.data.PantryItem`:
  - `shared/src/commonMain/sqldelight/com/loitu/yourrefri/shared/db/PantryEntity.sq`
  - `shared/src/commonMain/sqldelight/com/loitu/yourrefri/shared/db/UserShelfEntity.sq`
  - `shared/src/commonMain/sqldelight/com/loitu/yourrefri/shared/db/CookLogEntity.sq`
- Hạn sửa tay nằm ở **bảng riêng** `UserShelfEntity`, không phải cột của `PantryEntity`. Lý do: đặt hết, xóa dòng pantry hay `INSERT OR REPLACE` (SQLite xóa rồi chèn lại cả dòng) đều không được làm mất hạn tay; hạn tay cũng phải tồn tại khi món chưa từng có trong tủ.
- Ngày lưu dạng `TEXT` ISO `yyyy-MM-dd` (đúng `LocalDate.toString()`), so sánh chuỗi = so sánh ngày. Không dùng adapter cho ngày; repository tự đổi.
- `savedIngredientIds` lưu một cột `TEXT`, nối bằng dấu phẩy, qua `IdListAdapter` (không làm bảng phụ: chỉ đọc/ghi nguyên danh sách, không truy vấn theo từng món).
- Không lưu số lượng.
- Dialect mặc định (sqlite 3.18): dùng `INSERT OR REPLACE`, không dùng `ON CONFLICT DO UPDATE` hay `RETURNING`.
- Không có `CHECK` âm/dương trong schema; repository (W1-05) chặn số âm.

## Hợp đồng schema (test gọi đúng các tên này)

### `PantryEntity`
| Cột | Kiểu SQL | Kiểu Kotlin sinh ra |
|---|---|---|
| `ingredientId` | `TEXT NOT NULL PRIMARY KEY` | `String` |
| `have` | `INTEGER AS kotlin.Boolean NOT NULL` | `Boolean` (SQLDelight 2 hỗ trợ sẵn, không cần adapter) |
| `markedAt` | `TEXT NOT NULL` | `String` (ISO) |

| Query | Chữ ký sinh ra | Ngữ nghĩa |
|---|---|---|
| `upsert` | `upsert(ingredientId: String, have: Boolean, markedAt: String)` | `INSERT OR REPLACE` |
| `updateHave` | `updateHave(have: Boolean, ingredientId: String)` | `UPDATE ... SET have = :have WHERE ingredientId = :ingredientId`; không đổi `markedAt`, không tạo dòng |
| `selectAll` | `selectAll(): Query<PantryEntity>` | sắp theo `ingredientId ASC` |
| `selectById` | `selectById(ingredientId: String): Query<PantryEntity>` | |
| `deleteById` | `deleteById(ingredientId: String)` | |

### `UserShelfEntity`
| Cột | Kiểu SQL | Kiểu Kotlin |
|---|---|---|
| `ingredientId` | `TEXT NOT NULL PRIMARY KEY` | `String` |
| `userShelfDays` | `INTEGER NOT NULL` | `Long` (không dùng `AS Int` để khỏi cần thư viện `primitive-adapters`) |

| Query | Chữ ký | Ngữ nghĩa |
|---|---|---|
| `upsert` | `upsert(ingredientId: String, userShelfDays: Long)` | `INSERT OR REPLACE` |
| `selectById` | `selectById(ingredientId: String): Query<Long>` | chỉ chọn cột `userShelfDays` |
| `selectAll` | `selectAll(): Query<UserShelfEntity>` | sắp theo `ingredientId ASC` |
| `deleteById` | `deleteById(ingredientId: String)` | |

Không có khóa ngoại sang `PantryEntity`.

### `CookLogEntity`
Thứ tự cột cố định (test dùng constructor theo vị trí):

| Cột | Kiểu SQL | Kiểu Kotlin |
|---|---|---|
| `id` | `INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT` | `Long` |
| `recipeId` | `TEXT NOT NULL` | `String` |
| `cookedOn` | `TEXT NOT NULL` | `String` (ISO) |
| `photoUri` | `TEXT` (cho phép null) | `String?` |
| `savedIngredientIds` | `TEXT AS kotlin.collections.List<kotlin.String> NOT NULL` | `List<String>` (qua `IdListAdapter`) |

| Query | Chữ ký | Ngữ nghĩa |
|---|---|---|
| `insert` | `insert(recipeId: String, cookedOn: String, photoUri: String?, savedIngredientIds: List<String>)` | |
| `lastInsertRowId` | `lastInsertRowId(): Query<Long>` | `SELECT last_insert_rowid()` |
| `selectAll` | `selectAll(): Query<CookLogEntity>` | `ORDER BY cookedOn DESC, id DESC` (mới nhất trước; cùng ngày thì ghi sau đứng trước) |
| `selectSince` | `selectSince(since: String): Query<CookLogEntity>` | `cookedOn >= :since`, cùng thứ tự với `selectAll` |
| `selectRecipeIdsSince` | `selectRecipeIdsSince(since: String): Query<String>` | `SELECT DISTINCT recipeId ... WHERE cookedOn >= :since ORDER BY recipeId` |
| `deleteById` | `deleteById(id: Long)` | |

"Món nấu trong N ngày gần nhất" ở tầng DB là `selectRecipeIdsSince(since)`; việc đổi `N` + `today` thành `since` thuộc tầng gọi (W3-03/W3-05).

### Kotlin trong commonMain
- `shared/src/commonMain/kotlin/com/loitu/yourrefri/shared/db/DatabaseFactory.kt`:
  - `object IdListAdapter : ColumnAdapter<List<String>, String>`: `encode` nối bằng `","` giữ nguyên thứ tự và phần tử trùng; `""` ↔ `emptyList()`; `encode` ném `IllegalArgumentException` nếu một id rỗng hoặc chứa `,`.
  - `fun createDatabase(driver: SqlDriver): YourRefriDatabase` gắn `CookLogEntity.Adapter(savedIngredientIdsAdapter = IdListAdapter)`.
- `shared/src/androidMain/kotlin/com/loitu/yourrefri/shared/db/DriverFactory.kt`: `class DriverFactory(private val context: Context) { fun create(): SqlDriver = AndroidSqliteDriver(YourRefriDatabase.Schema, context, "yourrefri.db") }`. Không có unit test (cần Context thật); kiểm khi chạy app ở W1-07.

## Mutation dùng để rà

| Mã | Mutation (code sai) |
|----|---------------------|
| M1 | `PantryEntity` không có PRIMARY KEY hoặc `upsert` là `INSERT` thường (2 dòng trùng hoặc ném lỗi) |
| M2 | Ánh xạ `have` sai (đảo, hoặc luôn ghi 1) |
| M3 | `updateHave` cũng ghi đè `markedAt`, hoặc viết bằng upsert nên tạo dòng mới cho id lạ |
| M4 | `UPDATE`/`DELETE` thiếu `WHERE` (đổi/xóa mọi dòng) |
| M5 | Hạn tay là cột trong `PantryEntity` (mất khi `INSERT OR REPLACE` hoặc xóa dòng), hoặc khóa ngoại `ON DELETE CASCADE`, hoặc ghi hạn tay tạo luôn dòng pantry |
| M6 | `userShelfDays = 0` bị đổi thành null/xóa |
| M7 | `CookLogEntity.id` là `INTEGER PRIMARY KEY` không `AUTOINCREMENT` (dùng lại id vừa xóa) |
| M8 | Thứ tự `selectAll` sai: `ASC`, không có tie-break `id DESC`, hoặc không `ORDER BY` |
| M9 | `IdListAdapter.decode("")` trả `[""]`; sắp xếp hoặc bỏ trùng danh sách; dùng `toSet()` |
| M10 | `IdListAdapter.encode` không chặn id rỗng / chứa dấu phẩy (dữ liệu hỏng âm thầm) |
| M11 | `selectSince` dùng `>` thay `>=` |
| M12 | `selectRecipeIdsSince` thiếu `DISTINCT` hoặc không sắp xếp |
| M13 | `photoUri` NOT NULL hoặc ghi `""` thay null |
| M14 | `selectAll` của pantry/hạn tay không `ORDER BY ingredientId` |

## Khoảng trống đã biết

- `DriverFactory` (AndroidSqliteDriver) không có unit test; kiểm khi chạy app (W1-07).
- Chưa có migration: đây là schema v1. Mọi đổi schema sau này cần file `.sqm` + test migration riêng.
- Không kiểm `userShelfDays` âm ở tầng DB (chặn ở repository W1-05).
- Định nghĩa "N ngày gần nhất" (tính `since` từ `today` và `N`, có gồm hôm nay không) chưa chốt; thuộc W3-03/W3-05.
- Ngày chỉ đúng khi luôn là ISO 10 ký tự; repository W1-05 có test khóa định dạng ghi `markedAt`. `cookedOn` sẽ được khóa ở W3-05.
