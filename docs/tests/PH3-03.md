# PH3-03: Morning defrost reminder

## Contract
- Inputs: local today, weekly plan entries, recipes by id, ingredients (including `thit` / `ca` groups), and current pantry items.
- Expected: return a gentle `DefrostNotice` only when today's dinner exists and one of its recipe's meat/seafood required ingredient ids is currently `have` and `FREEZE`; include matching ids and today's date. Return null for missing dinner/recipe, non-meat/seafood, chilled or absent stock.
- Scheduling: when daily reminders are enabled, schedule a separate 08:00 local wall-clock alarm on every day. Keep existing daily reminder schedule independent; use same `daily_reminder` notification channel. Delivery routes by alarm kind and reschedules both.
- Boundaries: pure logic has no Android/database dependency; no edits to existing daily reminder content or once-daily state.
- Mutations: remove dinner-slot check; accept CHILL; ignore `have=false`; accept unrelated ingredient; change 08:00 to 09:00; suppress alarm when reminders disabled.
