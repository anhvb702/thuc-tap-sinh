# CR-01: Lite custom recipes

## Contract
- Repository `observeAll` starts empty, emits after insert/upsert/delete, and round-trips all `Recipe` fields.
- `addLite(title, ingredientIds)` requires a nonblank title and at least one unique nonblank ingredient ID; it creates one concise nonblank default step and one required slot per selected ingredient.
- `upsert` replaces the same recipe ID; `delete` removes only that ID.
- App recipe input is `bundledRecipes + customRecipes`, making the same IDs available to home suggestions, random pick, weekly plan, cooking, and history lookup.
- Recipes UI creates a lite recipe from title and ingredient multi-select, and offers delete for custom recipes.

## Tests and mutations
- Repository empty/round-trip/live flow test; catch omitted query emission, wrong field encoding, or missing mapping.
- Upsert/delete test; catch insert-only, deleting all rows, or wrong key.
- Lite validation/default step/slot test; catch skipped validation, missing step, or merged ingredients into a single alternative slot.
- UI source/logic test verifies title, ingredient selection, add callback, custom delete callback, and no emoji; catch removal of any action or text field.

## Sáu mutation
1. Bỏ kiểm tra tên trống: test validation phải fail.
2. Bỏ kiểm tra danh sách nguyên liệu rỗng: test validation phải fail.
3. Bỏ bước mặc định: test invariant bước nấu phải fail.
4. Gộp ingredient IDs thành một alternative slot: test Lite recipe phải fail.
5. Đổi upsert thành insert-only: test thay title theo cùng ID phải fail.
6. Xóa mọi recipe thay vì đúng ID: test giữ lại recipe thứ hai phải fail.
